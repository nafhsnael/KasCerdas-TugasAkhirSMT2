# 💰 KasCerdas - Web Manajemen Keuangan

## 📌 Deskripsi

KasCerdas adalah aplikasi berbasis web yang digunakan untuk membantu pengguna dalam mengatur dan mencatat keuangan secara lebih terstruktur. Aplikasi ini memungkinkan pengguna untuk mencatat pemasukan, pengeluaran, serta memantau kondisi keuangan secara real-time.

Dengan adanya aplikasi ini, diharapkan pengguna dapat lebih bijak dalam mengelola keuangan sehari-hari.

---

## 🎯 Fitur Utama

* Login & Register User
* Input Saldo Awal
* Pencatatan Transaksi (Pemasukan & Pengeluaran)
* Pilihan Bank / Dompet Digital
* Budget Bulanan
* Laporan Transaksi

---

## 🛠️ Teknologi yang Digunakan

* Frontend: React.js (Vite)
* Styling: CSS / Tailwind (opsional, sesuaikan)
* State Management: React Hooks
* Version Control: Git & GitHub

---

## 🚀 Cara Menjalankan Project

1. Clone repository:

```bash
git clone https://github.com/username/nama-repo.git
```

2. Masuk ke folder project:

```bash
cd nama-repo
```

3. Install dependencies:

```bash
npm install
```

4. Jalankan project:

```bash
npm run dev
```
